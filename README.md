# data-structure-lab# 数据结构学习实验室

面向初学者的数据结构与 C 语言交互学习网站。通过通俗讲解、分步动画、闯关练习和代码反馈，逐步理解数据怎样组织、算法怎样执行，以及怎样把它们写成 C 代码。

**[在线学习](https://t2446909-eng.github.io/data-structure-lab/)** · **[报告问题或提出建议](https://github.com/t2446909-eng/data-structure-lab/issues)**

## 可以学到什么

课程包含 6 个单元、40 个知识点。

| 单元 | 主要内容 |
| --- | --- |
| 基础概念与算法 | 数据与数据元素、数据对象、数据结构、ADT、算法、时间复杂度、空间复杂度 |
| 数据的组织方式 | 线性表、顺序表、链表、单链表、双链表、循环链表、栈、队列、串、数组 |
| 树与二叉树 | 二叉树、遍历、二叉搜索树、堆、哈夫曼树 |
| 图 | 存储方式、DFS、BFS、最短路径、最小生成树、拓扑排序 |
| 查找 | 顺序查找、二分查找、哈希查找、各种查找树 |
| 排序 | 冒泡、选择、插入、希尔、归并、快速、堆排序、基数排序 |

## 学习功能

- **逐步理解**。从具体问题和生活例子开始，解释术语、操作步骤、完整的小例子、常见误区，以及对应的 C 实现思路。
- **动手实验**。提供 81 个分步演示，每课至少两个例子。可切换例子、前进、回退、拖动进度和自动播放，跟踪数据与算法状态的变化。
- **闯关练习**。包含概念辨析、情境推演、实现与易错点。概念辨析共 175 题，各课根据知识范围、难度和重要程度安排 2–6 题，答题后提供解析。
- **C 代码练习**。支持自动缩进、格式整理、草稿保存、关键点评分和代码诊断，提供问题位置与修改提示。

## 开始学习

1. 打开在线网站，进入一个课程单元并选择知识点。
2. 先阅读「逐步理解」，用自己的话解释规则。
3. 打开「动手实验」，先预测下一步，再对照状态变化。
4. 完成「闯关练习」，根据解析回看容易混淆的地方。
5. 到「C 代码练习」编写实现，根据反馈修改，并用 C 编译器验证程序。

代码检查采用浏览器端静态分析和考察点评分。编译是否成功、实际输出是否符合要求，以及边界输入下的行为，需要通过 C 编译器运行验证。

学习记录和代码草稿保存在当前浏览器本地。

## 本地使用

下载本仓库，直接用浏览器打开 `index.html` 即可开始学习。

网站使用 HTML、CSS 和 JavaScript 实现，主页面、课程内容和交互逻辑集中在 `index.html` 中。当前版本可通过 GitHub Pages 发布。

## 参考教材

严蔚敏、吴伟民编著，《数据结构（C语言版）》，清华大学出版社，2007 年版，ISBN 9787302147510。

课程按教材相关章节安排学习主题，站内讲解、推演示例和练习围绕学习目标编写。各课页面提供对应章节信息。
